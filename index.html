🚀 Intercom Native Integration

JWT-First Approach - Intercom loads AFTER authentication

✅ Dynamic Loading Implementation

Intercom widget will only load AFTER you authenticate. This ensures the JWT is set in window.intercomSettings before the widget initializes.

ℹ️ How it works

1. You submit the form
2. Backend generates JWT token
3. JWT is set in window.intercomSettings
4. Intercom widget loads with JWT already configured
